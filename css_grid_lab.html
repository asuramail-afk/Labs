Grid と Flex の違い（content-out vs layout-in）

土台

Gridを学ぶ前の最重要分岐点。Flexは1次元（content-out＝中身が並びを決める）、Gridは2次元（layout-in＝先に枠を決めて流し込む）。同じ要素群を display:grid と display:flex で切り替え、行と列の「揃い」が保たれるかを見ます。

/* After: Grid = 枠を先に決める → 行も列も揃う */
.box { display: grid; grid-template-columns: repeat(3, 1fr); gap: 8px; }

/* Before: Flex = 中身のサイズで並ぶ → wrap すると列が揃わない */
.box { display: flex; flex-wrap: wrap; gap: 8px; }

01

用語マップ：line / track / cell / area

土台

Gridの全プロパティは結局この4要素を操作しているだけ。配置は内部的に必ず「どのラインからどのラインまで」に翻訳されます。ここを掴むと全プロパティが一本化されます。

/* ライン番号は 1 始まり。負の値は末尾から (-1 = 最終ライン) */
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* 列トラック×3 → 列ライン 1..4 */
  grid-template-rows: auto auto;       /* 行トラック×2 → 行ライン 1..3 */
  gap: 12px;                       /* track の「間」。cell ではない */
}
🔰 4要素の関係図
      col line: 1     2       3       4
               │     │       │       │
      row 1 ───┼─────┼───────┼───────┤
               │ cell│       │       │  ← track(列/行) = 隣接ラインに挟まれた帯
      row 2 ───┼─────┼───────┼───────┤
               │     │╔═════════════╗│
      row 3 ───┴─────┴╚═ area ══════╝┴  ← area = 4本のラインで囲まれた矩形
02

fr の正体：割合ではなく「残余の分配比」

土台

frは「全幅の割合（%）」ではなく、gap・固定幅・コンテンツ幅を差し引いた"残り"を比で分配する単位。だから1fr 1frはgapがあっても絶対はみ出さない。%はgapを計算に入れられず破綻します。下のデモは 200px 1fr 1fr（堅牢） ⇄ 200px 50% 50%（破綻）の切替です。

✓ After（fr＝残余を分配）
.grid {
  grid-template-columns:
    200px 1fr 1fr;
  gap: 12px;
}
/* 残り = 全幅 - 200px - gap
   を 1:1 で配る → 破綻しない */
✗ Before（%＝gap無視で破綻）
.grid {
  grid-template-columns:
    200px 50% 50%;
  gap: 12px;
}
/* 200 + 50% + 50% + gap
   = 100% 超 → はみ出す💥 */
現在: After（fr＝はみ出さない）
200px固定
fr / 50%
fr / 50%
After=3列が枠内に収まる / Before=3列目が枠外へはみ出し(クリップ)される
03

minmax() と「fr 暴走の罠」minmax(0,1fr)

トラック制御

最頻出の実務トラブル。1frは内部的にminmax(auto, 1fr)と等価で、最小幅がauto（≒min-content）。長いURLや画像、overflow未処理のflex子があると、その最小幅がトラックを押し広げ均等比が壊れます。minmax(0, 1fr)で最小0を許可すれば直ります。

✗ Before（崩れる）
grid-template-columns:
  1fr 1fr;
/* = minmax(auto,1fr)
   長い語が列を押し広げる */
✓ After（守られる）
grid-template-columns:
  minmax(0,1fr) minmax(0,1fr);
/* 最小0 → 比率維持＋省略 */
現在: After（minmax(0,1fr)）
thisisaveryveryverylongurltoken-pushes-track
右の列
After=左右が均等で長文は…省略 / Before=長文が左列を押し広げ右列が潰れる

auto-fit vs auto-fill（メディアクエリ無しの段組）

トラック制御

「列数をビューポート任せにしたい」への答え。repeat(auto-fit/auto-fill, minmax())で1行記述。違いはアイテムが列数より少ないときだけ現れる：auto-fitは空トラックを潰してアイテムを伸ばし、auto-fillは空トラックを残してアイテム幅を保ちます。

/* After: auto-fit → 空列を畳み、3個が伸びて幅いっぱい */
grid-template-columns: repeat(auto-fit, minmax(110px, 1fr));
/* Before: auto-fill → 空列を残し、3個は110pxのまま左寄り */
grid-template-columns: repeat(auto-fill, minmax(110px, 1fr));
現在: After（auto-fit＝伸びて充填）

ライン配置と span

土台

  grid-row: 2 / 4;
  /* 一括: grid-area: row-start / col-start / row-end / col-end; */
}

grid-template-areas（名前で組む）

配置と整列

Gridの思想を最も体現する機能。CSSのテキストがそのままレイアウトの「絵」になり、さらにDOM順とレイアウト順を分離できます（ソースはa11y優先のまま見た目だけ並べ替え可）。.で空セルを表現します。

.layout {
  grid-template-columns: 110px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}
.header { grid-area: header; }  /* 名前で配置 */

暗黙グリッド（grid-auto-rows / columns）

トラック制御

grid-template-*で定義した範囲を超えてアイテムが来ると、Gridが自動で行/列を生やします（暗黙トラック）。件数が不定（DBから返るカード数が可変）なときに必須。サイズを決めないと、はみ出た行が中身次第でガタつきます。

grid-template-columns: repeat(3, 1fr);
grid-auto-rows: 56px;   /* 暗黙的に増える行の高さを固定 → ガタつき防止 */
/* 列方向に自動配置するなら grid-auto-columns: 1fr; */

subgrid — 兄弟をまたいだ整列

応用

Grid最大の構造的欠陥だった「ネストしたグリッドは線を共有できない」を解消する機能。子が親のトラックライン（座標系）を間借りし、整列の責任を親へ集約します。カード一覧でタイトル行・本文・フッターをカードをまたいで揃えるのが代表例。

.card-list {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto auto auto;  /* 行を親で定義 */
}
.card {
  grid-row: span 3;
  display: grid;
  grid-template-rows: subgrid;  /* ★親の行ラインを継承 → 全カードで揃う */
}

実戦ギャラリー（auto-fit × subgrid 総合）

応用

これまでの総合。repeat(auto-fit, minmax())でレスポンシブな段組を作り、各カードはsubgridで行を揃える——実務でのカード一覧の完成形です。トグルでauto-fit(伸びる) ⇄ auto-fill(右に空き)の差を、ウィンドウ幅変更で列の再流し込みを確認できます。

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
  grid-template-rows: auto auto auto;
  gap: 10px;
}
.gallery .card { grid-row: span 3; display: grid; grid-template-rows: subgrid; }
